1. Create or open a sample (*LIMS > Samples*).
2. Choose a specimen-enabled product.
3. Leave *Lot / Serial* empty to auto-create one from the sample identifier.
4. *Current Location* shows the lot's stock location when a quant exists.
5. Use the **Lot / Serial** smart button to open the stock lot form.
6. Use **Move Lines** to list stock move lines for that lot.
7. Moving the serial in inventory updates the location when the sample is
   recomputed / reopened.
