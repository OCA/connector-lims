Link LIMS samples with customer invoices and vendor bills.

Invoice lines carry the analytes (parameters) being billed. The invoice
can also be linked to specific LIMS samples for reference. Smart buttons
navigate between samples and invoices in both directions.

Configuration
=============

1. Install **LIMS Account** (``lims_account``).
2. Ensure LIMS sample types are configured (*LIMS > Configuration*).

Usage
=====

1. On an invoice line, set **LIMS Analytes** to the parameters being
   billed.
2. Optionally set **LIMS Samples** on the invoice to link specific
   samples.
3. Use the **LIMS Samples** smart button on the invoice to open linked
   samples.
4. From a sample, use **Invoices** to open linked invoices, or create
   one.
