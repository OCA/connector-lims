Create LIMS samples automatically when sales orders are confirmed.

Configure each product with LIMS Tracking and LIMS Sample Type. On the sale
order line, select the analytes (parameters) to invoice/analyze. Tracking
modes: none, per order, per line, or per quantity.

On confirmation, samples are linked to one or more sales orders (M2M), and
each analysis is linked to the sale order line that sold that analyte.
Smart buttons connect the sales order and related samples.
