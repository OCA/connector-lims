Expose maintenance equipment as LIMS instruments.

Rather than introducing a separate instrument table, this module flags
maintenance equipment as LIMS instruments and surfaces them under the
LIMS menu, so laboratory equipment and its maintenance schedule stay in
one place.

**Table of contents**

.. contents::
   :local:

Configuration
=============

1. Install **LIMS Maintenance** (``lims_maintenance``).
2. Ensure the **Maintenance** app is available.
3. On any maintenance equipment, tick **LIMS Instrument** to flag it as
   a laboratory instrument.

Usage
=====

1. Go to *Maintenance → Equipment* and open an equipment record.
2. Tick **LIMS Instrument** to flag it as a laboratory instrument.
3. Go to *LIMS → Instruments* to see only the equipment flagged as LIMS
   instruments, and create new ones from there.
