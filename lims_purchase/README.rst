Link LIMS samples with purchase orders.

Extends ``lims`` and ``purchase`` so each purchase order can reference a
LIMS sample. The sample smart button opens linked purchase orders, or a
new form when none are linked yet.

**Table of contents**

.. contents::
   :local:

Configuration
=============

1. Install **LIMS Purchase** (``lims_purchase``).
2. Ensure LIMS sample types are configured (*LIMS > Configuration*).

Usage
=====

1. Open a LIMS sample and use **Purchase Orders** to open linked POs, or
   create one when none are linked.
2. From a purchase order, set **LIMS Sample** or use the smart button to
   open it.
